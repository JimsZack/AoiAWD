## 架构决策记录

### 零外部依赖
由于构建环境网络限制，所有外部依赖已替换为纯标准库实现：
| 原依赖 | 替代方案 | 说明 |
|--------|----------|------|
| go-chi/chi | net/http.ServeMux | 标准库路由 |
| google/uuid | crypto/rand + hex | 自实现 ID 生成 |
| gorilla/websocket | internal/ws | 手写 RFC 6455 最小实现 |
| fsnotify/fsnotify | syscall inotify | Linux 原生 inotify |
| creack/pty | os/exec 管道 | StdinPipe/StdoutPipe |
| modernc.org/sqlite | JSON 文件存储 | 纯 Go 文件持久化 |
| go.uber.org/zap | log | 标准库日志 |

### 存储后端
- **memory**（默认）: 纯内存存储，开箱即用，适合 CTF 比赛快速部署
- **file**: JSON 文件持久化，每 5 秒自动刷盘，重启后恢复数据
