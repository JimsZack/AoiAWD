# GoAWD 迁移指南

本文档提供从 AoiAWD (PHP) 迁移到 GoAWD (Go) 的详细指南。

## 1. 迁移概览

### 1.1 组件对应关系

| AoiAWD 组件 | GoAWD 组件 | 迁移难度 |
|-------------|------------|----------|
| AoiAWD Core (PHP) | GoAWD Core (Go) | 中 |
| Guardian (C) | GoAWD Guardian (Go) | 中 |
| RoundWorm (C) | GoAWD RoundWorm (Go) | 低 |
| Frontend (Vue.js) | 保持不变 | 无 |

### 1.2 迁移步骤

```
1. 部署 GoAWD Core Server
2. 迁移前端资源
3. 部署新探针
4. 测试验证
5. 切换流量
```

## 2. 数据迁移

### 2.1 存储后端

GoAWD 使用内置存储后端（内存或 JSON 文件），无需外部数据库。

- **内存存储**：数据仅在服务运行期间保留，重启后丢失
- **文件存储**：数据持久化到 JSON 文件，支持重启后恢复

## 4. 探针迁移

### 4.1 RoundWorm 迁移

**原 C 版本**:
```bash
./roundworm -s 192.168.1.1 -p 8023 -w "/var/www/html"
```

**新 Go 版本**:
```bash
./goawd-roundworm -s 192.168.1.1 -p 8023 -w "/var/www/html"
```

**参数映射**:
| 原参数 | 新参数 | 说明 |
|--------|--------|------|
| `-s` | `-s` | 服务器地址 |
| `-p` | `-p` | 服务器端口 |
| `-w` | `-w` | 监控目录 |
| `-i` | `-i` | 扫描间隔 |
| `-d` | `-d` | 守护进程模式 |

### 4.2 Guardian 迁移

**原 C 版本**:
```bash
./guardian /path/to/challenge
```

**新 Go 版本**:
```bash
./goawd-guardian -binary /path/to/challenge -host 192.168.1.1 -port 8023
```

## 5. 配置迁移

### 5.1 命令行参数对比

**AoiAWD (PHP)**:
```bash
php main.php \
    -w "tcp://0.0.0.0:1337" \
    -l "tcp://0.0.0.0:8023" \
    -t "your-token"
```

**GoAWD (Go)**:
```bash
./goawd-server \
    -http "0.0.0.0:1337" \
    -tcp "0.0.0.0:8023" \
    -token "your-token" \
    -storage memory
```

### 5.2 参数映射表

| PHP 参数 | Go 参数 | 说明 |
|----------|---------|------|
| `-w` | `-http` | HTTP 服务地址 |
| `-l` | `-tcp` | TCP 服务地址 |
| `-t` | `-token` | 访问令牌 |
| `-h` | `--help` | 帮助信息 |

## 6. 插件迁移

### 6.1 插件系统差异

| 特性 | AoiAWD (PHP) | GoAWD (Go) |
|------|--------------|------------|
| 插件格式 | .php 文件 | .go 文件 (编译时) |
| 加载方式 | 运行时 include | 编译时链接 |
| 热重载 | 支持 | 需要重新编译 |

### 6.2 内置插件迁移

以下插件已用 Go 重写：

- **FlagBuster**: Flag 检测与替换
- **KingWatcher**: 赛点文件监控
- **ZombieKiller**: 不死马检测

### 6.3 自定义插件迁移

将 PHP 插件转换为 Go 插件：

```go
// PHP 原版
class MyPlugin {
    public function processWebBuffer($data) {
        // 处理逻辑
        return $data;
    }
}

// Go 版本
type MyPlugin struct{}

func (p *MyPlugin) Name() string {
    return "MyPlugin"
}

func (p *MyPlugin) Register(m *plugin.Manager) {
    m.Register("Web", "processLog", p.processWebBuffer)
}

func (p *MyPlugin) processWebBuffer(data interface{}) interface{} {
    // 处理逻辑
    return data
}
```

## 8. 回滚方案

如果迁移失败，可以快速回滚：

```bash
# 1. 停止 GoAWD
pkill goawd-server

# 2. 重新部署 AoiAWD (需要保留原版代码)
# 注意：由于已删除旧组件，此回滚方案不再适用
# 建议在迁移前备份原版代码
```

## 9. 常见问题

### Q1: 原版探针能否继续使用？

**A**: 可以。GoAWD Core 完全兼容原版 AoiAWD 探针协议。

### Q2: 数据是否需要迁移？

**A**: GoAWD 使用内置存储后端，无需迁移数据。如果需要保留历史数据，可以导出原版 MongoDB 数据并转换为 JSON 格式。

### Q3: 插件是否需要重写？

**A**: 内置插件已用 Go 重写。自定义 PHP 插件需要转换为 Go 代码。

### Q4: 性能是否有提升？

**A**: 是的。Go 版本在以下方面有显著提升：
- 启动时间: <100ms (PHP: ~2s)
- 内存占用: ~15MB (PHP: ~50MB)
- 并发性能: 更高
- 无需外部数据库依赖

### Q5: 是否支持 Windows？

**A**: GoAWD Core 支持。但探针（RoundWorm/Guardian）依赖 Linux 特性，仅支持 Linux。
