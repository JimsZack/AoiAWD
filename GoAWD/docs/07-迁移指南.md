# GoAWD 迁移指南

本文档提供从 AoiAWD (PHP) 迁移到 GoAWD (Go) 的详细指南。

## 1. 迁移概览

### 1.1 组件对应关系

| AoiAWD 组件 | GoAWD 组件 | 迁移难度 |
|-------------|------------|----------|
| AoiAWD Core (PHP) | GoAWD Core (Go) | 中 |
| TapeWorm (PHP) | GoAWD Probe (Go/eBPF) | 高 (可选) |
| Guardian (C) | GoAWD Guardian (Go) | 中 |
| RoundWorm (C) | GoAWD RoundWorm (Go) | 低 |
| Frontend (Vue.js) | 保持不变 | 无 |

### 1.2 迁移步骤

```
1. 部署 MongoDB (可复用)
2. 部署 GoAWD Core Server
3. 迁移前端资源
4. 部署新探针
5. 测试验证
6. 切换流量
```

## 2. 数据迁移

### 2.1 MongoDB 数据兼容

GoAWD 使用相同的 MongoDB 集合结构，**数据完全兼容**。

```bash
# 如果使用独立的 MongoDB 实例，可以直接连接
# 如果需要迁移数据：

# 导出
mongodump --db aoiawd --out /backup/

# 导入
```

| filesystem | 文件系统日志 | 否 |

## 4. 探针迁移

### 4.1 RoundWorm 迁移

**原 C 版本**:
```bash
./roundworm -s 192.168.1.1 -p 8023 -w "/var/www/html"
```

**新 Go 版本**:
```bash
./goawd-roundworm -s 192.168.1.1 -p 8023 -w "/var/www/html"
```

**参数映射**:
| 原参数 | 新参数 | 说明 |
|--------|--------|------|
| `-s` | `-s` | 服务器地址 |
| `-p` | `-p` | 服务器端口 |
| `-w` | `-w` | 监控目录 |
| `-i` | `-i` | 扫描间隔 |
| `-d` | `-d` | 守护进程模式 |

### 4.2 Guardian 迁移

**原 C 版本**:
```bash
./guardian /path/to/challenge
```

**新 Go 版本**:
```bash
./goawd-guardian -binary /path/to/challenge -host 192.168.1.1 -port 8023
```

### 4.3 TapeWorm 处理

TapeWorm 是 PHP 特有的探针，有两种迁移方案：

**方案 A: 保留 PHP 版本（推荐）**
- 如果目标应用是 PHP，继续使用原版 TapeWorm
- GoAWD Core 完全兼容原版探针协议

**方案 B: 使用 eBPF 方案（高级）**
- 实现 eBPF 探针替代 TapeWorm
- 适用于所有类型的应用
- 需要额外开发

## 5. 配置迁移

### 5.1 命令行参数对比

**AoiAWD (PHP)**:
```bash
php main.php \
    -w "tcp://0.0.0.0:1337" \
    -l "tcp://0.0.0.0:8023" \
    -m "mongodb://127.0.0.1:27017" \
    -t "your-token"
```

**GoAWD (Go)**:
```bash
./goawd-server \
    -http "0.0.0.0:1337" \
    -tcp "0.0.0.0:8023" \
    -mongo "mongodb://127.0.0.1:27017" \
    -token "your-token"
```

### 5.2 参数映射表

| PHP 参数 | Go 参数 | 说明 |
|----------|---------|------|
| `-w` | `-http` | HTTP 服务地址 |
| `-l` | `-tcp` | TCP 服务地址 |
| `-m` | `-mongo` | MongoDB URI |
| `-t` | `-token` | 访问令牌 |
| `-h` | `--help` | 帮助信息 |

## 6. 插件迁移

### 6.1 插件系统差异

| 特性 | AoiAWD (PHP) | GoAWD (Go) |
|------|--------------|------------|
| 插件格式 | .php 文件 | .go 文件 (编译时) |
| 加载方式 | 运行时 include | 编译时链接 |
| 热重载 | 支持 | 需要重新编译 |

### 6.2 内置插件迁移

以下插件已用 Go 重写：

- **FlagBuster**: Flag 检测与替换
- **KingWatcher**: 赛点文件监控
- **ZombieKiller**: 不死马检测

### 6.3 自定义插件迁移

将 PHP 插件转换为 Go 插件：

```go
// PHP 原版
class MyPlugin {
    public function processWebBuffer($data) {
        // 处理逻辑
        return $data;
    }
}

// Go 版本
type MyPlugin struct{}

func (p *MyPlugin) Name() string {
    return "MyPlugin"
}

func (p *MyPlugin) Register(m *plugin.Manager) {
    m.Register("Web", "processLog", p.processWebBuffer)
}

func (p *MyPlugin) processWebBuffer(data interface{}) interface{} {
    // 处理逻辑
    return data
}
```

## 8. 回滚方案

如果迁移失败，可以快速回滚：

```bash
# 1. 停止 GoAWD
pkill goawd-server

# 2. 启动 AoiAWD
php /path/to/aoiawd/main.php \
    -w "tcp://0.0.0.0:1337" \
    -l "tcp://0.0.0.0:8023" \
    -m "mongodb://127.0.0.1:27017"

# 3. 验证
curl http://localhost:1337/api/ping
```

## 9. 常见问题

### Q1: 原版探针能否继续使用？

**A**: 可以。GoAWD Core 完全兼容原版 AoiAWD 探针协议。

### Q2: 数据是否需要迁移？

**A**: 如果使用同一个 MongoDB 实例，无需迁移。数据结构完全兼容。

### Q3: 插件是否需要重写？

**A**: 内置插件已用 Go 重写。自定义 PHP 插件需要转换为 Go 代码。

### Q4: 性能是否有提升？

**A**: 是的。Go 版本在以下方面有显著提升：
- 启动时间: <100ms (PHP: ~2s)
- 内存占用: ~10MB (PHP: ~50MB)
- 并发性能: 更高

### Q5: 是否支持 Windows？

**A**: GoAWD Core 支持。但探针（RoundWorm/Guardian）依赖 Linux 特性，仅支持 Linux。
