# GoAWD 项目概述

## 1. 项目简介

GoAWD 是 AoiAWD 的 Golang 重写版本，专为 CTF AWD (Attack With Defense) 模式设计的轻量级 EDR (Endpoint Detection and Response) 系统。

**原项目**: AoiAWD (PHP + C)
**重写版本**: GoAWD (Go)
**开源协议**: GNU AGPL-3.0

## 2. 重写动机

| 特性 | AoiAWD (PHP) | GoAWD (Go) |
|------|--------------|------------|
| 并发模型 | 协程 (amphp) | goroutine (原生) |
| 部署方式 | 需要 PHP 运行时 | 单二进制文件 |
| 内存占用 | ~50MB+ | ~10MB |
| 启动速度 | ~2s | <100ms |
| 类型安全 | 弱类型 | 强类型 |
| 交叉编译 | 困难 | 原生支持 |
| 探针部署 | 需要运行时 | 静态编译 |

## 4. 核心组件

### 4.1 GoAWD Core Server

中心数据处理与API服务器，负责：
- HTTP API 提供 RESTful 接口
- TCP 接收器收集探针数据
- WebSocket 实时推送告警
- 插件系统支持动态扩展
- MongoDB 数据持久化

### 4.2 RoundWorm-Go

系统/文件/进程监控探针：
- 使用 `fsnotify` 监控文件系统变化
- 使用 `/proc` 伪文件系统监控进程
- 支持 daemon 模式
- 单二进制静态编译

### 4.3 Guardian-Go

PWN 行为探针：
- 使用 `creack/pty` 创建伪终端
- 透明劫持 stdin/stdout
- 上报流量和内存映射
- 支持 ELF 捆绑器

### 4.4 TapeWorm-Go (可选)

Web 行为探针（PHP 特有）：
- 如果目标是 PHP 应用，可保留 PHP 版本
- 或者使用 eBPF 方案替代（高级）

## 5. 技术栈

| 组件 | 技术选型 |
|------|----------|
| HTTP 框架 | chi/gin |
| WebSocket | gorilla/websocket |
| MongoDB 驱动 | go.mongodb.org/mongo-driver |
| 文件监控 | fsnotify |
| PTY 操作 | creack/pty |
| 日志 | zap/logrus |
| 配置 | viper |
| CLI | cobra/urfave/cli |
