# GoAWD 项目概述

## 1. 项目简介

GoAWD 是专为 CTF AWD (Attack With Defense) 模式设计的轻量级 EDR (Endpoint Detection and Response) 系统。

**原项目**: AoiAWD (PHP + C)
**重写版本**: GoAWD (Go)
**开源协议**: MIT

## 2. 重写动机

| 特性 | AoiAWD (PHP) | GoAWD (Go) |
|------|--------------|------------|
| 并发模型 | 协程 (amphp) | goroutine (原生) |
| 部署方式 | 需要 PHP 运行时 | 单二进制文件 |
| 内存占用 | ~50MB+ | ~15MB |
| 启动速度 | ~2s | <100ms |
| 类型安全 | 弱类型 | 强类型 |
| 交叉编译 | 困难 | 原生支持 |
| 探针部署 | 需要运行时 | 静态编译 |
| 外部依赖 | MongoDB + PHP | 零外部依赖 |

## 4. 核心组件

### 4.1 GoAWD Core Server

中心数据处理与 API 服务器，负责：
- HTTP API 提供 RESTful 接口
- TCP 接收器收集探针数据
- WebSocket 实时推送告警
- 插件系统支持动态扩展
- 内置存储 (内存/文件)

### 4.2 RoundWorm-Go

系统/文件/进程监控探针：
- 使用 `inotify` 系统调用监控文件系统变化
- 使用 `/proc` 伪文件系统监控进程
- 支持 daemon 模式
- 单二进制静态编译

### 4.3 Guardian-Go

PWN 行为探针：
- 使用管道模式劫持 stdin/stdout
- 上报流量和内存映射
- 单二进制部署

### 4.4 TapeWorm-Go

Web 行为探针：
- PHP 文件注入 `ob_start` 钩子
- 捕获 HTTP 请求/响应
- 支持流量篡改
- 支持移除模式

## 5. 技术栈

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| HTTP 框架 | `net/http` | Go 标准库 |
| WebSocket | 手写 RFC 6455 | 零外部依赖 |
| 存储 | 内存/JSON 文件 | 内置实现 |
| 文件监控 | `syscall` inotify | 直接系统调用 |
| 进程扫描 | `/proc` 伪文件系统 | 直接读取 |
| TCP 通信 | `net` 标准库 | JSON 行协议 |
| 插件系统 | `plugin` 标准库 | .so 动态加载 |

**零外部依赖**: 整个项目完全基于 Go 标准库实现
