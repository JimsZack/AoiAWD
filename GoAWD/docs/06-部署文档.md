# GoAWD 部署文档

## 1. 环境要求

### 1.1 服务端 (GoAWD Core)

- **操作系统**: Linux (推荐 Ubuntu 20.04+)
- **Go 版本**: 1.21+
- **MongoDB**: 4.4+
- **内存**: 512MB+
- **磁盘**: 1GB+

### 1.2 探针 (RoundWorm/Guardian)

- **操作系统**: Linux
- **架构**: amd64 / arm64

## 2. 编译构建

### 2.1 从源码编译

```bash
# 克隆代码
git clone https://github.com/your-org/goawd.git
cd goawd

# 下载依赖
go mod download

# 编译所有组件
make build

# 或者单独编译
go build -o bin/goawd-server ./cmd/server
go build -o bin/goawd-roundworm ./cmd/roundworm
go build -o bin/goawd-guardian ./cmd/guardian
```

### 2.2 交叉编译

```bash
# Linux amd64
GOOS=linux GOARCH=amd64 go build -o bin/goawd-server-linux-amd64 ./cmd/server

# Linux arm64
GOOS=linux GOARCH=arm64 go build -o bin/goawd-server-linux-arm64 ./cmd/server

# 静态编译（不依赖 libc）
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o bin/goawd-server ./cmd/server
```

### 2.3 Docker 构建

```bash
# 构建镜像
docker build -t goawd:latest .

# 运行容器
docker-compose up -d
```

## 3. 服务端部署

### 3.1 单机部署

```bash
# 1. 启动 MongoDB
mongod --dbpath /data/db --port 27017

# 2. 启动 GoAWD Server
./goawd-server \
    -http "0.0.0.0:1337" \
    -tcp "0.0.0.0:8023" \
    -mongo "mongodb://127.0.0.1:27017" \
    -token "your-access-token"
```

### 3.2 Docker Compose 部署

```yaml
# docker-compose.yml
version: '3.8'

services:
  mongodb:
    image: mongo:6.0
    container_name: goawd-mongodb
    ports:
      - "27017:27017"
    volumes:
      - mongodb_data:/data/db
    networks:
      - goawd-network

  goawd-server:
    build: .
    container_name: goawd-server
    ports:
      - "1337:1337"   # HTTP
      - "8023:8023"   # TCP
    environment:
      - MONGODB_URI=mongodb://mongodb:27017
      - TOKEN=your-access-token
    depends_on:
      - mongodb
    networks:
      - goawd-network

networks:
  goawd-network:
    driver: bridge

volumes:
  mongodb_data:
```

### 3.3 Systemd 服务

```ini
# /etc/systemd/system/goawd.service
[Unit]
Description=GoAWD Server
After=network.target mongodb.service

[Service]
Type=simple
User=goawd
Group=goawd
ExecStart=/opt/goawd/goawd-server \
    -http "0.0.0.0:1337" \
    -tcp "0.0.0.0:8023" \
    -mongo "mongodb://127.0.0.1:27017" \
    -token "your-access-token"
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

## 4. 探针部署

### 4.1 RoundWorm (文件/进程监控)

```bash
# 部署到靶机
scp goawd-roundworm target:/opt/

# 运行
ssh target
/opt/goawd-roundworm \
    -s "192.168.1.1" \
    -p 8023 \
    -w "/var/www/html;/tmp" \
    -i 100ms
```

### 4.2 Guardian (PWN 流量劫持)

```bash
# 方式1: 直接绑定
./goawd-guardian \
    -binary /path/to/challenge \
    -host 192.168.1.1 \
    -port 8023

# 方式2: 生成捆绑二进制（通过 API）
curl -X POST http://192.168.1.1:1337/api/v1/generatepwnbin \
    -H "Content-Type: application/json" \
    -d '{"binary": "base64-elf-content", "host": "192.168.1.1", "port": 8023}' \
    -o guardian-challenge
chmod +x guardian-challenge
./guardian-challenge
```

### 4.3 批量部署脚本

```bash
#!/bin/bash
# deploy.sh - 批量部署探针

SERVER_IP="192.168.1.1"
SERVER_PORT=8023
TARGETS=("192.168.0.1" "192.168.0.2" "192.168.0.3")
SSH_USER="root"
SSH_PASS="password"

for TARGET in "${TARGETS[@]}"; do
    echo "Deploying to $TARGET..."
    
    # 复制探针
    sshpass -p "$SSH_PASS" scp goawd-roundworm $SSH_USER@$TARGET:/opt/
    sshpass -p "$SSH_PASS" scp goawd-guardian $SSH_USER@$TARGET:/opt/
    
    # 启动 RoundWorm
    sshpass -p "$SSH_PASS" ssh $SSH_USER@$TARGET \
        "nohup /opt/goawd-roundworm -s $SERVER_IP -p $SERVER_PORT -w '/var/www/html' &"
    
    echo "Deployed to $TARGET"
done
```

## 5. 前端部署

### 5.1 构建前端

```bash
cd Frontend
npm install
npm run build

# 复制到 GoAWD
cp -r dist/* ../GoAWD/public/
```

### 5.2 Nginx 反向代理（可选）

```nginx
# /etc/nginx/sites-available/goawd
server {
    listen 80;
    server_name goawd.example.com;

    location / {
        proxy_pass http://127.0.0.1:1337;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /websocket {
        proxy_pass http://127.0.0.1:1337;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

## 6. 配置说明

### 6.1 命令行参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `-http` | `0.0.0.0:1337` | HTTP 服务监听地址 |
| `-tcp` | `0.0.0.0:8023` | TCP 接收器监听地址 |
| `-mongo` | `mongodb://127.0.0.1:27017` | MongoDB 连接 URI |
| `-token` | 随机生成 | API 访问令牌 |
| `-db` | `aoiawd` | 数据库名称 |
| `-plugins` | `./plugins` | 插件目录 |

### 6.2 环境变量

```bash
export GOAWD_HTTP_ADDR="0.0.0.0:1337"
export GOAWD_TCP_ADDR="0.0.0.0:8023"
export GOAWD_MONGODB_URI="mongodb://127.0.0.1:27017"
export GOAWD_TOKEN="your-access-token"
```

## 8. 常见问题

### 8.1 MongoDB 连接失败

```
Error: connection failed
```

**解决方案**:
- 检查 MongoDB 是否启动
- 检查防火墙是否开放 27017 端口
- 验证连接 URI 格式

### 8.2 端口被占用

```
Error: bind: address already in use
```

**解决方案**:
```bash
# 查找占用端口的进程
lsof -i :1337
lsof -i :8023

# 终止进程或修改监听端口
```

### 8.3 权限不足

```
Error: permission denied
```

**解决方案**:
```bash
# 使用非特权端口 (>1024)
./goawd-server -http "0.0.0.0:1337" -tcp "0.0.0.0:8023"

# 或使用 sudo
sudo ./goawd-server
```
