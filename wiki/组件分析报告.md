# GoAWD 组件分析报告

## 项目概述

GoAWD 是专为 CTF AWD 竞赛设计的轻量级 EDR 系统，采用 Go 语言实现，零外部依赖。

## 组件清单

### 1. GoAWD Server (核心服务器)

**路径**: `GoAWD/cmd/server/`

**职责**:
- 提供 HTTP API 服务 (端口 1337)
- 接收探针数据 (端口 8023)
- WebSocket 实时推送
- 插件管理
- 数据存储

**代码统计**:
- 入口文件: 85 行
- 核心运行时: 727 行
- API 层: 658 行
- 存储层: 434 行

**依赖**:
- 无外部依赖
- 纯 Go 标准库实现

### 2. GoAWD RoundWorm (文件/进程探针)

**路径**: `GoAWD/cmd/roundworm/`

**职责**:
- 监控文件系统变更
- 扫描新进程
- 上报事件到服务器

**代码统计**:
- 入口文件: 97 行
- inotify 封装: 200 行
- 进程扫描: 204 行
- TCP 客户端: 47 行

**特性**:
- 基于 syscall 的 inotify 实现
- /proc 伪文件系统扫描
- 支持守护进程模式

### 3. GoAWD Guardian (PWN 探针)

**路径**: `GoAWD/cmd/guardian/`

**职责**:
- 劫持 PWN 程序 stdin/stdout
- 捕获内存映射
- 上报流量到服务器

**代码统计**:
- 入口文件: 173 行

**特性**:
- 管道模式劫持
- 读取 /proc/pid/maps
- 双 TCP 连接 (stdin/stdout)

### 4. GoAWD TapeWorm (PHP Web 探针)

**路径**: `GoAWD/cmd/tapeworm/`

**职责**:
- 注入 PHP 文件监控代码
- 移除注入代码
- 测试连接

**代码统计**:
- 入口文件: 309 行

**特性**:
- 递归扫描 PHP 文件
- ob_start 钩子注入
- 支持 remove 模式

### 5. 内置插件

#### FlagBuster

**路径**: `GoAWD/plugins/flagbuster/`

**功能**: 检测并替换 Web/PWN 输出中的 flag

**代码统计**: 88 行

**检测模式**:
- `flag{...}` 格式
- `{"flag":"..."}` 格式

#### KingWatcher

**路径**: `GoAWD/plugins/kingwatcher/`

**功能**: KoH 模式赛点文件监控

**代码统计**: 57 行

**特性**:
- 默认监控 `/flag`
- 支持环境变量配置

#### ZombieKiller

**路径**: `GoAWD/plugins/zombiekiller/`

**功能**: 不死马行为检测

**代码统计**: 79 行

**检测逻辑**:
- 跟踪删除事件
- 检测快速重建行为
- 5 秒时间窗口

### 6. Frontend (Vue.js 前端)

**路径**: `Frontend/`

**技术栈**:
- Vue.js 2.2
- Element UI 1.2
- Vuex 2.x
- Vue Router 2.x
- Webpack 2.x

**功能模块**:
- 仪表板
- Web 日志查看
- PWN 日志查看
- 文件日志查看
- 进程日志查看
- 告警日志查看

### 7. Guardian C 版 (备用)

**路径**: `Guardian/`

**状态**: 备用组件，已被 Go 版替代

**特性**:
- ELF 捆绑器
- forkpty 实现
- PHP 打包脚本


## 总结

GoAWD 是一个设计精良、功能完整的 CTF AWD 竞赛 EDR 系统：

1. **零外部依赖**: 无需 PHP、MongoDB 等外部服务
2. **单二进制部署**: 编译后直接运行
3. **功能完整**: 覆盖 Web/PWN/文件/进程监控
4. **插件系统**: 支持动态扩展
5. **文档齐全**: 8 篇详细文档 + Wiki
