# 功能介绍

GoAWD 是一个功能完整的 CTF AWD 竞赛 EDR 系统。

## 核心功能

### 1. Web 流量监控

- **请求捕获**: 记录所有 HTTP 请求的完整内容
- **响应捕获**: 记录服务器响应内容
- **流量篡改**: 支持实时修改响应内容
- **数据展示**: Web 面板可视化展示流量

**支持的数据**:
- 请求方法 (GET/POST/PUT/DELETE)
- 请求 URI
- 请求头
- GET/POST 参数
- Cookie
- 响应体 (Base64 编码)

### 2. PWN 流量捕获

- **stdin 捕获**: 记录用户输入
- **stdout 捕获**: 记录程序输出
- **内存映射**: 读取 `/proc/pid/maps`
- **流量重放**: 支持生成重放脚本

**应用场景**:
- 分析 exploit payload
- 重放攻击流量
- 生成攻击二进制

### 3. 文件系统监控

- **实时监控**: 基于 inotify 的实时事件
- **事件类型**: CREATE/MODIFY/DELETE/MOVE
- **内容捕获**: 读取变更文件内容
- **递归监控**: 支持子目录监控

**监控目录**:
- Web 根目录
- 临时目录
- 自定义目录

### 4. 进程行为监控

- **新进程检测**: 扫描 `/proc` 检测新进程
- **进程列表**: 维护当前存活进程
- **进程信息**: PID/PPID/UID/命令行

**检测目标**:
- 反弹 shell
- 挖矿程序
- 可疑进程

## 插件系统

### 内置插件

| 插件 | 功能 | 触发时机 |
|------|------|----------|
| FlagBuster | 检测并替换 flag | Web/PWN 响应处理 |
| KingWatcher | 赛点文件监控 | 文件系统事件 |
| ZombieKiller | 不死马检测 | 文件系统事件 |

### 插件机制

- **注册**: 通过 `init()` 注册到全局插件列表
- **钩子**: 基于 routine/operation 的钩子系统
- **热加载**: 支持 .so 插件动态加载

## Web 管理面板

### 功能模块

1. **仪表板**: 系统状态、告警统计
2. **Web 日志**: 流量查看、详情分析
3. **PWN 日志**: 流量查看、二进制生成
4. **文件日志**: 文件事件查看
5. **进程日志**: 进程信息查看
6. **告警日志**: 插件告警汇总

### 实时更新

- WebSocket 实时推送
- 数据变更即时刷新
- 无需手动刷新页面

## 通信协议

### TCP JSON 行协议

所有探针通过 TCP 连接到服务器，使用 JSON 格式通信：

```json
{"type":"web","data":{...}}
{"type":"pwn","data":{...}}
{"type":"file","data":{...}}
{"type":"new_process","data":{...}}
{"type":"pid_list","data":[...]}
{"type":"ping","data":[]}
```

### 消息类型

| 类型 | 说明 | 数据格式 |
|------|------|----------|
| `web` | Web 请求/响应 | WebLogData |
| `pwn` | PWN 流量 | PWNInitData/PwnProcess |
| `file` | 文件事件 | FileEventData |
| `new_process` | 新进程 | ProcessData |
| `pid_list` | PID 列表 | []int |
| `ping` | 心跳 | [] |

## 安全特性

### API 认证

- Token 认证机制
- 随机生成访问令牌
- 请求频率限制

### 数据保护

- 路径遍历防护
- Shell 命令注入防护
- 上传大小限制

### 隐私保护

- 数据仅在本地存储
- 不收集用户信息
- 支持内存存储模式
