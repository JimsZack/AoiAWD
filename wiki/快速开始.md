# 快速开始

本指南将帮助你在 5 分钟内运行 GoAWD 系统。

## 方式一：Docker 部署（推荐）

### 前置条件
- Docker 已安装
- Docker Compose 已安装

### 步骤

```bash
# 1. 克隆项目
git clone https://github.com/JimsZack/AoiAWD.git
cd AoiAWD

# 2. 启动服务
docker compose up -d

# 3. 访问 Web 面板
# 打开浏览器访问: http://localhost:1337
```

### 查看访问令牌

```bash
# 查看容器日志获取令牌
docker compose logs | grep -i token
```

## 方式二：源码编译

### 前置条件
- Go 1.21+
- Node.js 16+ (用于前端构建)

### 步骤

```bash
# 1. 克隆项目
git clone https://github.com/JimsZack/AoiAWD.git
cd AoiAWD

# 2. 编译后端
cd GoAWD
make build

# 3. 构建前端
cd ../Frontend
npm install
npm run build

# 4. 复制前端到 GoAWD
cp -r dist/* ../GoAWD/public/

# 5. 启动服务器
cd ../GoAWD
./bin/goawd-server -storage file -file-path "./goawd.json"
```

## 方式三：快速构建脚本

```bash
# 1. 克隆项目
git clone https://github.com/JimsZack/AoiAWD.git
cd AoiAWD

# 2. 运行构建脚本
chmod +x build.sh
./build.sh

# 3. 解压并运行
tar -xzf GoAWD-*.tar.gz
cd GoAWD-*
./bin/goawd-server
```

## 部署探针

### 文件/进程监控探针 (RoundWorm)

```bash
# 在靶机上运行
./goawd-roundworm \
    -s <服务器IP> \
    -p 8023 \
    -w "/var/www/html;/tmp" \
    -d
```

### PWN 流量劫持探针 (Guardian)

```bash
# 在靶机上运行
./goawd-guardian \
    -binary /path/to/pwn/challenge \
    -host <服务器IP> \
    -port 8023
```

## 验证安装

```bash
# 检查服务状态
curl http://localhost:1337/api/ping

# 预期返回
# {"status":"ok"}
```
